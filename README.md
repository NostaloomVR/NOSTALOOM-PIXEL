# NOSTALOOM Pixel Pet OS

Retro pixel-style Android launcher for Redmi Note 8 (Android 10).

## Latest testing build: v0.12

- [Download Android APK v0.12](releases/v0.12/NOSTALOOM-Pixel-Pet-OS-v0.12-DEBUG.apk)
- [Download source ZIP v0.12](releases/v0.12/NOSTALOOM-Pixel-Pet-OS-v0.12-source.zip)

Features: purple dot-matrix clock, dark purple dotted backdrop, interactive Mochi cat, app shortcuts, and notification badges for TikTok/YouTube/WhatsApp/Facebook.

**Test build:** not yet verified on a physical Redmi Note 8. Notification access requires user permission in Android settings.
